# 용어 사전 (Glossary)

이 문서는 대부호 프로젝트에서 사용하는 공통 용어를 정의합니다.
Claude와 사용자가 같은 의미로 소통하기 위한 기준입니다.

---

## 게임 구조

| 용어 | 설명 |
|------|------|
| **게임** | 카드를 나눠주고 모든 플레이어가 카드를 다 낼 때까지 진행하여 순위를 결정하는 단위 |
| **판** | 선 플레이어가 카드를 처음 내려놓으면 시작하고, 다음 선이 정해지기 전까지의 단위 |
| **선** | 해당 판에서 첫 번째로 카드를 내는 플레이어 |
| **턴** | 한 플레이어가 카드를 내거나 패스하는 차례 |

---

## 플레이어 계급

| 한국어 | 영문 (코드) | 설명 |
|--------|------------|------|
| **대부호** | `president` | 가장 먼저 패를 다 낸 플레이어 |
| **부호** | `vice-president` | 두 번째로 패를 다 낸 플레이어 (4명 이상) |
| **평민** | `citizen` | 중간 순위 플레이어. 첫 게임은 모두 평민으로 시작 |
| **빈민** | `vice-scum` | 뒤에서 두 번째로 패를 다 낸 플레이어 (4명 이상) |
| **대빈민** | `scum` | 마지막까지 카드가 남은 플레이어 |

---

## 카드

| 용어 | 설명 |
|------|------|
| **손패** | 플레이어가 현재 들고 있는 카드 묶음 |
| **테이블 카드** | 현재 판에서 바닥에 내려진 카드 |
| **조커** | 최강 카드. 단독으로 내면 최강, 다른 카드와 함께 내면 와일드카드로 취급 |
| **혁명** | 같은 숫자 4장을 내면 발동. 카드 강약 순서가 역전됨 |
| **반혁명** | 혁명 상태에서 다시 혁명이 발동된 것. 순서가 원래대로 돌아옴 |
| **8-Clear** | 숫자 8을 내면 즉시 판 종료 |
| **♠ Reversal** | 조커만 테이블에 있을 때 ♠3을 내면 즉시 판 종료 |

---

## 세금

| 용어 | 설명 |
|------|------|
| **세금** | 2번째 게임부터 게임 시작 전, 하위 계급이 상위 계급에게 강한 카드를 바치는 규칙 |

---

## UI / 화면 요소

| 용어 | 설명 |
|------|------|
| **손패 영역** | 화면 하단, 내 카드가 표시되는 영역 (`#my-area`) |
| **액션 바** | 손패 영역 위에 위치한 버튼 조작 영역. 카드 내기·패스·나가기 버튼 포함 (`#action-btns`) |
| **내 정보 패널** | 손패 영역 왼쪽 상단에 붙은 패널. 내 이름·계급·카드 수를 표시 (`#my-panel`) |
| **플레이어 시트** | 각 플레이어의 이름/카드수/계급을 보여주는 원형 배치 패널 |
| **테이블** | 화면 중앙, 현재 판에 내려진 카드가 표시되는 영역 |
| **Glow** | 현재 턴인 플레이어를 강조하는 테두리 빛나는 효과 |
